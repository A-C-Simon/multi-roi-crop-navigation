# Historical experiments

[EXPERIMENT_NOTES.md](EXPERIMENT_NOTES.md) preserves the original research
notes, with dash punctuation normalized. It describes the local photo dataset,
observed failures, and configurations that were retained or rejected.
It is an archive, not an installation guide. Old paths and commands refer to
the original repository layout.

The `results` directory contains the six original detector CSV tables. The
associated photographs and image outputs remain in the
[original repository](https://github.com/A-C-Simon/Crop_row_detection/tree/main/LinReg/MultiROI).
Those tables are historical records and were not regenerated for this release.

No labeled ground truth accompanies these results. Reported navigation angles
are estimates, not error metrics. Use [the current usage guide](../usage.md)
for commands in this distribution.
