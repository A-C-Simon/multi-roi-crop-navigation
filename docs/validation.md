# Validation

## Automated checks

The test suite contains eight synthetic checks covering missing plants,
persistent corridor shifts, width changes, straight and slanted corridors,
drawing coverage, and short heading excursions.

Run the checks from the repository root:

```bash
python -m pip install -e '.[dev]'
python -m pytest
```

## Continuous integration

[GitHub Actions](https://github.com/A-C-Simon/multi-roi-crop-navigation/actions/workflows/checks.yml)
runs the following workflow on Python 3.10, 3.11, and 3.12:

| Check | Verification |
| --- | --- |
| Installation | Install the package and check dependency compatibility |
| Source snapshot | Compare source and asset checksums with the recorded import |
| Regression tests | Run all eight synthetic checks |
| Command-line tools | Exercise help for all three installed commands |
| Image processing | Generate inputs and verify two readable output composites |
| Video processing | Verify a 40-frame output video and its CSV records |
| Packaging | Build the wheel and source archive |

The workflow checks the output files as well as the command exit status.

## Field image example

The included field photograph provides a repeatable example for inspecting
segmentation, selected strip regions, and the fitted corridor:

```bash
multiroi-detect --input examples/field --results_dir outputs/field-example
```

The README preview is generated by this command. See
[image details](assets/README.md) for the original input and its checksum.

## Source verification

Run this command to compare the preserved source and asset files with their
recorded SHA-256 checksums:

```bash
python scripts/verify_snapshot.py
```

The source revision and file list are recorded in
[source-snapshot.json](source-snapshot.json).

## Reproducing a run

Keep the input, command, dependency versions, output composite, and matching CSV
records together. For simulation runs, also record the selected world and
launch arguments. This makes configurations and results easier to compare.
